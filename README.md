## 📍 Descripción del Proyecto

Esta es una aplicación web del clima minimalista y responsiva, diseñada para demostrar el consumo de **APIs externas** y la **manipulación del DOM** utilizando **JavaScript puro** (VanillaJS).

El proyecto se enfoca en proporcionar una interfaz de usuario limpia y moderna, permitiendo a los usuarios buscar información climática por nombre de ciudad.

## 🚀 Características Principales

* **Búsqueda Dinámica:** Permite buscar el clima de cualquier ciudad global.
* **Diseño Responsivo:** Interfaz que se adapta a dispositivos móviles y de escritorio.
* **Información Detallada:** Muestra temperatura, descripción del clima, humedad, velocidad del viento y sensación térmica.
* **Consumo de API:** Manejo eficiente de llamadas `fetch` y promesas para obtener datos en tiempo real.

## ⚙️ Instrucciones de Instalación y Uso

Sigue estos pasos para ejecutar la aplicación localmente:

1.  **Clonar el Repositorio:**
    ```bash
    git clone [https://github.com/aarongomez0/VanillaJS-Weather-App.git](https://github.com/aarongomez0/VanillaJS-Weather-App.git)
    cd VanillaJS-Weather-App
    ```

2.  **Configurar la API Key:**
    * Este proyecto requiere una clave de API en: https://www.weatherapi.com
    * Crea una cuenta en Weather API
    * Abre el archivo `script.js` y reemplaza la cadena con tu clave personal.

3.  **Ejecutar:**
    * Simplemente abre el archivo `index.html` en tu navegador web.
